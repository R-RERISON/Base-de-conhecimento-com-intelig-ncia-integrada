Base de conhecimento corporativa com Search lexical, governança editorial, classificação, revisão, estrutura semântica e experiência pública em evolução.

== Description ==

O BDC consolida capacidades de gestão de conhecimento em um único plugin WordPress.

A baseline atual inclui:
* Search lexical canônico.
* Retrieval por post e seção.
* Deep links e identidade estável.
* Golden Queries.
* Classificação e governança editorial.
* Content Extractor / Knowledge Document.
* Public Experience em evolução controlada.
* Word Cloud BDC-owned.

A versão 1.0.0 ainda não foi liberada. O projeto utiliza gates de engenharia e homologação antes de cutover/retirement de legados.

== Installation ==

1. Instale o ZIP do plugin pelo WordPress.
2. Ative o plugin.
3. Valide compatibilidade e gates aplicáveis no ambiente de homologação antes de produção.
