# UX-001 — Checklist de QA do Protótipo

## Viewports

- [ ] 1440px — desktop largo.
- [ ] 1024px — desktop estreito.
- [ ] 782px — breakpoint WordPress.
- [ ] ~492px — mobile de contingência.

## Knowledge List

- [ ] busca permanece utilizável;
- [ ] título é a informação dominante;
- [ ] colunas secundárias desaparecem antes de comprometer legibilidade;
- [ ] ação `Gerenciar` permanece alcançável;
- [ ] não existe status de Review inventado.

## Workspace

- [ ] contexto do artigo permanece visível;
- [ ] tabs Visão geral / Summary / Classificação são claras;
- [ ] Context Panel reflowa abaixo do conteúdo em largura estreita;
- [ ] Review & Governança aparece somente como futuro/reserva;
- [ ] referência legada não parece valor canônico.

## Summary

- [ ] três campos e somente três campos canônicos;
- [ ] labels explícitos;
- [ ] ação primária clara;
- [ ] feedback de sucesso textual.

## Classificação

- [ ] audiência multi;
- [ ] equipe responsável multi;
- [ ] tipo de conhecimento single;
- [ ] item de catálogo multi;
- [ ] nenhum campo histórico extra aparece como canônico.

## Acessibilidade

- [ ] foco visível;
- [ ] ordem de Tab acompanha ordem visual;
- [ ] controles possuem labels;
- [ ] status não depende somente de cor;
- [ ] nenhum controle depende de hover;
- [ ] sem overflow horizontal funcional em 782px/492px.

## Resultado

Gate UX-030 só pode passar com todos os itens aplicáveis marcados PASS e evidência registrada.
