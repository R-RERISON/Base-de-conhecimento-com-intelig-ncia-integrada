== Description ==

Base de Conhecimento com Inteligência Integrada (BDC) consolidates knowledge management capabilities into a single WordPress plugin.

The current development baseline includes:

* Canonical lexical search.
* Post and section retrieval.
* Stable result identities and deep links.
* Golden Queries and deterministic rebuilds.
* Editorial classification and review governance.
* Content Extractor and Knowledge Document contracts.
* A controlled public experience candidate.
* A BDC-owned Word Cloud implementation.

Version 1.0.0 has not been released. The project uses explicit engineering, parity, security, packaging, and environmental gates before production cutover or retirement of legacy components.

== Installation ==

1. Install the approved plugin ZIP through WordPress.
2. Activate the plugin.
3. Validate the applicable compatibility and environment gates before production promotion.
4. Do not remove legacy plugins solely because a newer BDC build is installed.

== Upgrade Notice ==

Review UPGRADE.md and the release evidence before promoting a build between environments.
