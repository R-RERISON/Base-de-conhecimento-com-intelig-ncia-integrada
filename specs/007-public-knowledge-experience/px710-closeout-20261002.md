## Frozen product shape

Primary journey:
`Home -> Search -> Results -> Article Reader -> official action/context`.

Home:
- Search-first;
- exploration secondary/progressive;
- no dashboard-first treatment.

Reader:
- documentation workspace;
- strong reading width;
- contextual right rail;
- compact global Search;
- no duplicated legacy chrome.

## Frozen ownership

BDC owns:
- Public Home/Reader shell;
- public header presentation;
- Search UI/results presentation;
- categories/latest/popular read models;
- Word Cloud presentation/read model;
- Helpful Tips presentation;
- Executive Summary rail;
- scoped public CSS/JS;
- preview/cutover routing contract.

WordPress owns:
- canonical request/permalink/session/capabilities;
- post content and categories;
- the_content lifecycle.

Entra Gateway owns:
- auth/SSO protocol and profile-menu behavior.

GAC owns:
- PostActions/KnowledgeBridge/observation.

WP Unified Indexer owns:
- current anchor injection until explicit disposition.

GRE:
- no longer canonical owner of Tips/summary storage;
- remains active renderer on legacy public surface;
- candidate Reader may suppress duplicate GRE renderers only inside the controlled candidate request.

## Frozen data semantics

Latest:
- publish only;
- category optional;
- date DESC, ID DESC.

Popular:
- publish only;
- category optional;
- comment_count DESC, date DESC, ID DESC.

Search:
- canonical Public_Search_Facade;
- no second ranker;
- authorization revalidation;
- WordPress fallback preserved.

Word Cloud:
- BDC snapshot only;
- no regeneration in public request.

Helpful Tips:
- canonical key `_bdc_es_helpful_tips`;
- ordered `title/content` items.
