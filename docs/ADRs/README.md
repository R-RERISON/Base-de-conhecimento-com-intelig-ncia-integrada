# ADRs — Architectural Decision Records

Decisões estruturais relevantes devem ser registradas aqui usando `.specify/templates/adr-template.md`.

## Quando ADR é obrigatória

- criar tabela própria;
- introduzir REST como contrato público;
- introduzir framework/biblioteca de runtime;
- escolher metadata versus taxonomy quando impacto for amplo;
- adotar queue própria;
- escolher estratégia de vector store;
- escolher algoritmo de hybrid rank;
- introduzir provider de IA;
- alterar fonte da verdade;
- divergir da Constituição;
- mudança destrutiva ou de difícil rollback.

## Numeração

`ADR-0001-titulo.md`, `ADR-0002-titulo.md`, ...

## Regra

ADR registra decisão e trade-off; não substitui SPEC.
